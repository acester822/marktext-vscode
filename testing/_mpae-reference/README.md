# _mpae-reference — imported test files (NOT part of the active suite)

These files were pulled in from **Markdown Preview Aces Edition (MPAE)**, a
different extension with a much larger feature set than this muya-based editor
supports (code-chunk execution, `@import`, interactive vega, TOC, kroki/
wavedrom/graphviz/ditaa diagrams, `$$$` math, block attributes, …).

They are **preserved here as historical reference only** and are NOT part of
the active visual test suite. If you open them in the MarkText WYSIWYG editor,
most special features will render as plain code blocks (which is expected —
this editor doesn't implement them).

For the current, curated test documents use the sibling files (`01-basics.md`
… `09-footnotes-frontmatter.md`) plus `00-INDEX.md`.
